CIRCUITS

Read-only. GET and HEAD are the only methods this server implements, it binds 127.0.0.1 and nothing else, and nothing outside a declared circuit is reachable at any depth. Writing to disk is a later, separate circuit.

FOR AN ARTIFACT

Include client/mains.js by relative path — it works from either power source — then branch on Mains.plugged. Read Mains.help() in a console for the rest. An artifact must never require the mains: if cutting the power breaks it, the artifact is wrong.

FOR A CIRCUIT

One line in mains.json. Roots only, never files — what is inside a circuit is answered by the filesystem at the moment it is asked, so this list cannot go stale the way a catalog can. A vanished root is reported DEAD here rather than quietly dropped.

TO CUT THE POWER

ctrl-c in the terminal running it. Everything in the tree keeps working immediately afterward, on batteries, because that is the only property this project is not allowed to break.
